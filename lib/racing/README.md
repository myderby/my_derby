# MY DERBY 경주 시뮬레이션 0.1.0
개발안 V3의 5구간(0~15 / 15~35 / 35~65 / 65~85 / 85~100%), 0.2초 동시 갱신, 경주마 9개 능력 및 기수 8개 능력, 전략 1~3안, 200m 구간 순위, 구조화된 사건 로그, 결승 시각 순위를 구현한 **초기 밸런싱 엔진**입니다.

- `engine.ts`: 결정적 RNG, 입력 검증, 조교 상태/체력/속도/레인/전략/결승/로그 계산
- `types.ts`: 입출력 계약
- `demo.ts`: 19, 20, 21시 시연에 사용하는 12두 가상 데이터
- `app/api/race/simulate/route.ts`: 테스트용 서버 실행 POST API. Supabase에 **절대 기록하지 않음**.
- `npm run test:race`: 경주 검증

**주의:** 수치는 물리 법칙·실제 KRA 경주 기록을 통한 보정값이 아닙니다. 개발안의 계수와 게임 밸런스 전체가 확정된 것이 아니며, 실제 운영/상금/시즌 일정을 자동 갱신하지 않습니다. 게임 월드의 실제 출전마·전략 스냅샷·기수 신청 정보를 읽어 공식 경주로 반영하는 연동은 후속 구현 대상입니다.
